# Διαχείριση Εξοπλισμού (Χρέωση / Αποχρέωση)

Εφαρμογή web για τη διαχείριση χρέωσης και αποχρέωσης εξοπλισμού από τεχνικούς, με:

- **Email ειδοποίηση** κάθε φορά που κάποιος εξοπλισμός **χρεώνεται** ή **αποχρεώνεται**.
- **Δικαιώματα ανά χρήστη**: κάθε τεχνικός βλέπει και διαχειρίζεται **μόνο τις δικές του** χρεώσεις. Ο διαχειριστής (admin) βλέπει και διαχειρίζεται τα πάντα.

## Τεχνολογίες

Node.js, Express, SQLite (better-sqlite3), EJS templates, express-session, bcryptjs, nodemailer. Δεν χρειάζεται εξωτερική βάση δεδομένων — όλα αποθηκεύονται τοπικά σε αρχείο SQLite (`data/app.sqlite`).

## Εγκατάσταση

```bash
npm install
cp .env.example .env
```

Ανοίξτε το `.env` και συμπληρώστε:

1. `SESSION_SECRET` — μια τυχαία τιμή (π.χ. `openssl rand -hex 32`).
2. `ADMIN_USERNAME`, `ADMIN_PASSWORD`, `ADMIN_EMAIL` — στοιχεία του πρώτου λογαριασμού διαχειριστή.
3. Τα στοιχεία **SMTP** (`SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`) — ο διακομιστής αποστολής email. Για Gmail χρειάζεται [App Password](https://myaccount.google.com/apppasswords), όχι ο κανονικός κωδικός.
4. `NOTIFY_EMAIL` — το email που θα λαμβάνει τις ειδοποιήσεις χρέωσης/αποχρέωσης.

Δημιουργήστε τον αρχικό λογαριασμό διαχειριστή:

```bash
npm run seed
```

Εκκίνηση:

```bash
npm start
```

Η εφαρμογή θα είναι διαθέσιμη στο `http://localhost:3000`.

## Λειτουργία

### Ρόλοι

- **Διαχειριστής (admin)**: διαχειρίζεται τον κατάλογο εξοπλισμού, δημιουργεί λογαριασμούς τεχνικών, βλέπει/διαχειρίζεται όλες τις χρεώσεις.
- **Τεχνικός (technician)**: βλέπει τον κατάλογο εξοπλισμού, δημιουργεί νέες χρεώσεις, βλέπει και αποχρεώνει **μόνο τις δικές του** χρεώσεις. Δεν έχει καμία πρόσβαση στις χρεώσεις άλλων τεχνικών — προσπάθεια πρόσβασης επιστρέφει σφάλμα 403.

Οι λογαριασμοί τεχνικών δημιουργούνται από τον διαχειριστή στη σελίδα **Χρήστες**.

### Χρέωση εξοπλισμού

Ο τεχνικός επιλέγει διαθέσιμο εξοπλισμό, συμπληρώνει σε ποιον χρεώνεται και προαιρετικές σημειώσεις. Ο εξοπλισμός γίνεται "Χρεωμένος" και αποστέλλεται email ειδοποίησης στο `NOTIFY_EMAIL`.

### Αποχρέωση εξοπλισμού

Μόνο ο τεχνικός που έκανε τη χρέωση (ή ο διαχειριστής) μπορεί να την αποχρεώσει. Ο εξοπλισμός επιστρέφει σε κατάσταση "Διαθέσιμος" και αποστέλλεται email ειδοποίησης.

## Σημείωση για τα email

Αν δεν έχουν ρυθμιστεί σωστά τα στοιχεία SMTP στο `.env`, η εφαρμογή δεν θα αποτύχει — απλώς θα καταγράψει προειδοποίηση στο log και θα συνεχίσει κανονικά.
